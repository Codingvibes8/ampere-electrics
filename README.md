# AmpereElectricJamez Website

A professional portfolio website for a NAPIT-approved electrician serving North West London. This site features a modern, high-performance design with advanced animations and a focus on user experience and conversion.

## Features

- **Modern Tech Stack**: Built with **Next.js 15.1.7**, **React 19**, **Tailwind CSS v4**, and **TypeScript**.
- **High Performance**: Optimized for speed with server components, code splitting, and image optimization.
- **Advanced Animations**: Features smooth scrolling, micro-interactions, and immersive page transitions powered by `framer-motion` and custom CSS.
- **Rich UI Components**:
  - **Navbar**: Sticky header with dynamic state changes on scroll.
  - **Hero Section**: Interactive elements with a dynamic "Circuit Backdrop" SVG animation.
  - **Services**: Visually appealing grid layout for different electrical services with interactive badges.
  - **About Section**: Professional layout with trust signals and member showcases.
  - **Testimonials**: Carousel of customer reviews.
  - **Process**: Step-by-step guide to the service process.
  - **Footer**: Comprehensive footer with contact details and site map.
- **Design System**:
  - Custom color palette (`Ink`, `Volt`, `Snow`, `Mist`).
  - Dark-themed design with high-contrast accents.
  - Custom typography: `Archivo` (body), `Big Shoulders Display` (headers), `JetBrains Mono` (mono/tech).
- **SEO Optimized**: Includes rich metadata, Open Graph tags, and structured content for search engines.

## Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd ampere-electrics
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

## Usage

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser. (Note: The dev server might use port 3001 if 3000 is in use).
